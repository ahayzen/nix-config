# Blu-ray

Can be used as a cheap offline WORM backup of data, see [Archive](./../guides/backup/blu-ray.md).

## Disc sizes

Multiple sizes are available of 25G, 50G, 100G, 128G.

> We use Bluray defect management which reserves space on the disk

## Single layer

Advertised: 25G
Space: 11826176 sectors, 2048 sector size, 24220008448 bytes total (23098 MiB)

## Triple layer

Advertised: 100G
Space: 47305728 sectors, 2048 sector size, 96882130944 bytes total (92394 MiB)
