# Mikrotik hAP ax3

## Configuration

  * Set Country in Quickset to "United Kingdom"
  * Set Frequency Range of 5GHz to 5470-5735MHz (Band B)
  * Set Channel Width of 5GHz to 20/40/80MHz
  * Set Channel Width of 2.4GHz to 20MHz
